### 🛠️ About me

- 🔩 I build systems **from scratch** to learn how they really work: a database, an LLM serving engine, GPU kernels and a consensus fuzzer.
- 🌍 I also apply ML to real problems: wildfire forecasting, stroke rehabilitation and predictive maintenance.
- 🧪 I care about testing: deterministic simulation, Jepsen-style checks and differential fuzzing.

### 🚀 Featured projects

<table>
<tr>
<td width="50%" valign="top">

#### 🗄️ [Halyard](https://github.com/Vaibhav1067/Halyard)
A Redis-compatible database in Go, with **Raft written from scratch**. It has linearizable reads, live shard migration and **~400 ms failover with zero lost writes**. You can run the Raft code in your browser (WASM).

`Go` `Raft` `WASM` `Jepsen-style tests`

</td>
<td width="50%" valign="top">

#### 🧠 [Tensorline](https://github.com/Vaibhav1067/Tensorline)
An LLM inference engine built from scratch, with a paged KV cache, continuous batching, CUDA graphs, speculative decoding and custom Triton kernels. **4.0× Ollama's throughput** on one RTX 3050.

`Python` `Triton` `CUDA` `OpenAI API`

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 🔍 [diffuzz-btc](https://github.com/Vaibhav1067/diffuzz-btc)
A differential fuzzer for Bitcoin consensus. It sends the same cases to Bitcoin Core, btcd, NBitcoin, libbitcoin and rust-bitcoin. **~418M script cases** run so far.

`Rust` `Fuzzing` `Bitcoin`

</td>
<td width="50%" valign="top">

#### 🔥 [AgniDrishti](https://github.com/Vaibhav1067/AgniDrishti)
A weekly wildfire risk forecast for Uttarakhand, trained with XGBoost on 10 years of NASA FIRMS data (**PR-AUC 0.85**). It has SHAP explanations, district alerts and an interactive map.

`XGBoost` `SHAP` `Leaflet`

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 📈 [QuantPair](https://github.com/Vaibhav1067/QuantPair)
A statistical arbitrage platform. It finds pairs with Engle–Granger tests and FDR control, and includes a backtester with costs, walk-forward validation and a live spread monitor.

`FastAPI` `Next.js` `Statistics`

</td>
<td width="50%" valign="top">

#### 🗣️ [RehabMind](https://github.com/Vaibhav1067/RehabMind)
Speech and language practice for people with aphasia after a stroke, kept within limits each patient's clinician sets. It runs fully locally with Whisper and Qwen2.5.

`TypeScript` `Whisper` `Local LLM`

</td>
</tr>
